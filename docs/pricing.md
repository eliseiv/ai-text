# Оплата, цены и лимиты

Документ — предложение для согласования. Все числа задаются в `.env`, код менять не нужно.

## 1. Каналы оплаты (как в соседних сервисах)

Три канала, как в `claude-ios` и `ai-media-upscaler`. Все они уже есть в ядре шаблона и проходят
через один журнал платежей (`PaymentsJournal`). Кредиты за покупку определяет только сервер по
каталогу `PRODUCTS`, и повторная доставка не начисляет их дважды.

| Канал | Кто платит | Поток | Подтверждение |
|---|---|---|---|
| **App Store (StoreKit 2)** | iOS, любой регион | покупка в приложении → `POST /v1/subscription/sync` (подписка) или `POST /v1/tokens/purchase` (пакет) с подписанной транзакцией | подпись JWS до корневого сертификата Apple; повтор той же транзакции не начисляет (restore) |
| **Adapty** | iOS через SDK Adapty | Adapty шлёт `POST /v1/billing/adapty/webhook`: старт и продление подписки, покупка пакета (`non_subscription_purchase`), истечение, возврат. Отключение автопродления доступ не забирает | Bearer `ADAPTY_WEBHOOK_SECRET`; один грант на период, даже если пришли и `trial_started`, и `subscription_started` |
| **CloudPayments / broadapps (РФ)** | RU-витрина (условие — remote config Adapty `pay=true` + RU storefront, как в `claude-ios`) | приложение вызывает `POST /v1/billing/cloudpayments/checkout` → получает `paymentUrl` → открывает в SFSafariViewController → после закрытия опрашивает `GET /v1/plan` | вебхук без подписи — только сигнал; сервер перепроверяет платёж через API broadapps (`CLOUDPAYMENTS_API_TOKEN`, статус `succeeded`, окно свежести 72 ч). Срок доступа — ровно один `period` продукта; досрочное продление прибавляется к текущему сроку |

**Одна покупка Apple — одно начисление.** Транзакция Apple может прийти дважды: из приложения
(`/v1/subscription/sync`, `/v1/tokens/purchase`) и вебхуком Adapty. Оба канала начисляют под
общим ключом (`sub-grant:<transaction id>` или `token-purchase:<transaction id>`), поэтому кредиты
начисляются один раз.

### Возвраты

| Источник | Сигнал | Что делает сервер |
|---|---|---|
| Adapty | `subscription_refunded`, `non_subscription_purchase_refunded` | отзывает кредиты покупки; для подписки ещё и закрывает доступ |
| App Store | отозванная транзакция в `/v1/subscription/sync` или `/v1/tokens/purchase` | то же; за отозванную транзакцию кредиты не начисляются |
| CloudPayments | вебхук `OperationType=Refund` (только сигнал) | через API broadapps проверяет, что платёж в статусе `CLOUDPAYMENTS_REFUNDED_STATUSES` (по умолчанию `refunded`), и отзывает, если мы этот платёж начисляли |

Правила возврата:
- **Кредиты:** забираются только в пределах текущего баланса. Уже потраченные не взыскиваются,
  так как баланс не может уйти в минус. Недобор записывается в журнал (`creditsNotRecovered`).
- **Подписка:** при возврате подписки доступ закрывается сразу.
- **Идемпотентность:** повтор вебхука или сообщение о том же возврате по другому каналу (Adapty и
  App Store) ничего не списывает повторно.
- **Журнал:** возврат пишется в `payments` отдельной строкой (`kind=refund`, `status=refunded`),
  рядом с исходным начислением. Списание — строка ledger с ключом `refund:<ключ начисления>`.

Состояния из ТЗ (ожидается подтверждение / оплачено / отменено / ошибка / истёк доступ / возврат)
клиент показывает по `GET /v1/plan` (`subscriptionStatus`, `canAsk`, `blockReason`) и по
`GET /v1/payments`. Возврат со страницы оплаты ничего не меняет, пока платёж не подтверждён
сервером.

После покупки незавершённое действие (вопрос или конспект в статусе `blocked`) клиент повторяет
явно через `…/retry`. Автоматического списания нет.

## 2. Каталог (`PRODUCTS`)

Идентификаторы продуктов такие же, как у соседних сервисов. Магазин и RU-кабинет уже настроены
под эти ID.

| productId | Тип | Кредиты | App Store (ориентир) | RU (`PLAN_DISPLAY`) |
|---|---|---|---|---|
| `week_6.99_nottrial` | подписка, неделя | 100 за период | $6.99 | 599 ₽ |
| `yearly_49.99_nottrial` | подписка, год | 800 за период | $49.99 | 3 990 ₽ |
| `100_Tokens_9.99` | пакет | 100 | $9.99 | 790 ₽ |
| `250_Tokens_19.99` | пакет | 250 | $19.99 | 1 590 ₽ |
| `500_Tokens_34.99` | пакет | 500 | $34.99 | 2 790 ₽ |
| `1000_Tokens_59.99` | пакет | 1 000 | $59.99 | 4 790 ₽ |

Правила ядра, общие для всех сервисов:
- кредиты тратятся только при активной подписке;
- пакеты — докупка для подписчиков (`403 subscription_required` без подписки);
- кредиты не сгорают, остаток переносится;
- без подписки — одна бесплатная генерация на аккаунт (`TRIAL_ENABLED`) плюс 3 бесплатных
  вопроса в демо-теме (`DEMO_FREE_QUESTIONS`).

Пакета на 2 000 кредитов ($99.99), как у соседей, здесь нет: при полном расходе он уходит в минус
(см. §4).

## 3. Цены операций

| Операция | Кредиты | Настройка |
|---|---|---|
| Импорт PDF, текста, статьи | 0 | обработка без LLM (извлечение и индекс в Postgres) |
| Вопрос → ответ с цитатами | **1** | `ANSWER_CREDITS` |
| Конспект, до 150 000 символов материалов | **3** | `SUMMARY_CREDITS` |
| Конспект, каждая следующая часть до 120 000 символов | **+2** | `SUMMARY_CREDITS_PER_EXTRA_PART` |
| Конспект по тем же версиям материалов повторно | 0 | возвращается готовый (`reused`) |
| Ошибка, отмена, блокировка | 0 | ядро списывает только за готовый результат |

Максимум за конспект: 3 + 2 × 7 = **17 кредитов** (не больше 8 частей, `SUMMARY_MAX_BATCHES`;
остальное помечается `coverage.partial`). Точную цену до запуска отдаёт
`GET /v1/topics/{id}/summaries/price`. Этот расчёт использует ту же функцию разбиения, что и сама
генерация, поэтому показанная цена всегда совпадает со списанной.

## 4. Себестоимость (OpenAI, цены из `claude-ios` на 2026-08-14)

Цены за 1 млн токенов: `gpt-5.1` — вход $1.25, кэш $0.125, выход $10; `gpt-5-mini` — вход $0.25,
выход $2. Оценка: около 3 символов русского текста на токен (с запасом), рассуждения — на
уровне `low`.

| Операция | Токены (оценка) | Себестоимость |
|---|---|---|
| Ответ, небольшая тема (~20 тыс. символов) | ~7k вход + ~2k выход | ≈ $0.03 |
| Ответ, максимальный контекст (100 тыс. символов) | ~34k вход + ~2k выход + проверка цитат на `gpt-5-mini` | ≈ $0.065 |
| Уточняющий вопрос по той же теме (кэш префикса) | вход в основном из кэша | ≈ $0.025 |
| Конспект, 1 часть (до 150 тыс. символов) | ~50k вход + ~4k выход | ≈ $0.10 |
| Конспект, дополнительная часть (120 тыс.) | ~40k вход + ~4k выход | ≈ $0.09 |

Средняя себестоимость кредита — **$0.03–0.04**, в худшем случае около $0.065.

| Продукт | Выручка после комиссии Apple 30% / 15% | Худший случай: все кредиты на максимальной нагрузке | Типичный случай |
|---|---|---|---|
| Неделя, 100 кредитов | $4.9 / $5.9 | ≈ $6.5 | ≈ $3.5 |
| Год, 800 кредитов | $35 / $42.5 | ≈ $52 | ≈ $28 |
| Пакет 1 000 | $42 / $51 | ≈ $65 | ≈ $35 |

Типичный случай окупается с маржой. Худший случай (каждый вопрос по 100 тыс. символов без кэша)
уходит в минус, как и у соседних сервисов. Страховка — лимиты ниже. Если после запуска средняя
себестоимость кредита окажется выше $0.04, рычаги такие:
- `OPENAI_SUMMARY_MODEL=gpt-5-mini` — конспект дешевле примерно в 5 раз;
- уменьшить `ANSWER_CONTEXT_CHARS`;
- поднять `SUMMARY_CREDITS`;
- уменьшить кредиты в годовом тарифе.

## 5. Лимиты

| Лимит | Значение | Зачем |
|---|---|---|
| PDF | 30 МБ, 300 страниц, нужен текстовый слой | 300 стр. ≈ 750 тыс. символов ≈ 7 частей конспекта |
| Вставленный текст | 50 – 300 000 символов | |
| Веб-статья | 1 страница, 5 МБ HTML | без обхода сайта |
| Материалов в теме | 20 | |
| Тем на пользователя | 100 | |
| Хранилище | 1 ГБ на пользователя | |
| Контекст ответа | 100 000 символов, дальше отбор фрагментов (`partialContext`) | потолок себестоимости ответа |
| Вопрос | 2 000 символов | |
| Генераций в минуту | 20 на пользователя (`RATE_LIMIT_GENERATION_PER_USER`) | защита от скриптов |
| Одновременных генераций | 3 на пользователя (`GENERATION_MAX_INFLIGHT_PER_USER`) | |
| Потолок цены одной операции | 100 кредитов (`PRICING_MAX_CREDITS_PER_GENERATION`) | защита от ошибки конфигурации |

Все лимиты клиент получает до отправки через `GET /v1/limits`. Цены, остаток и продукты — через
`GET /v1/plan`.

## 6. Решено

- **Срок подписки CloudPayments** берётся из `period` продукта в `PRODUCTS` (`P1W`, `P1M`,
  `P1Y`). Для подписки, продаваемой через CloudPayments, `period` обязателен: без него продукт не
  загрузится, и в логе будет предупреждение.
- **Возвраты** обрабатываются по всем трём каналам (см. §1).
- **Цены** — конфигурация (`PRODUCTS`, `ANSWER_CREDITS`, `SUMMARY_CREDITS*`, `PLAN_DISPLAY`).
  Модель: подписка с кредитами за период плюс пакеты кредитов.
- **OpenAI** — сервис размещается на зарубежном сервере, прокси не нужен (`OPENAI_PROXY_URLS`
  пустой).
